About this project

Linux Command Trainer is an open-source, framework-free web app for learning the Linux command line by doing - built with plain HTML, CSS and modern JavaScript.

How it works

The command reference is a single JSON database of 160+ commands across 24 categories, each with syntax, parameters, worked examples, common mistakes and tips. The terminal simulator implements a real virtual filesystem in memory - every mkdir, cp and rm genuinely changes state, pipes and redirection work, and practice challenges verify your solutions against that live state rather than pattern-matching your keystrokes.

Quizzes are generated from the same database: hand-written questions for tricky commands, plus auto-generated multiple-choice, fill-in-the-blank and true/false questions, so the pool stays fresh. All progress - XP, streaks, achievements, notes, favorites - lives in your browser's Local Storage. Nothing is sent anywhere.

Tech stack

HTML5, CSS3 (custom properties, glassmorphism, dark/light themes) and vanilla ES modules. No frameworks, no build step, no dependencies. Works offline as a PWA once visited. Deployable to GitHub Pages as-is.

Contributing

Found a mistake in a command page, or want to add one? Every command is one JSON object in data/commands.json - see the README for the schema and the contribution guide. Bug reports and pull requests are welcome.
